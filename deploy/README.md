# Frankies Lagos

Single-file site for Frankies Lagos, a burger, sub and bubble tea shop in Ikeja, Lagos.

Everything lives in `index.html`: markup, styles, scripts, fonts and images are all inlined,
so the file opens by double-clicking it with no server and no build step.

## Editing

Open the page and add `#/edit` to the address, or press Ctrl+Shift+E (Cmd+Shift+E on a Mac).
An editor panel opens over the live page. Change prices, photos, the event banner, contact
details, hours, the map and the story, then press Save. A new `index.html` lands in Downloads.
Replace this one with it and commit.

Nothing is uploaded anywhere. The editor runs entirely in the browser.
